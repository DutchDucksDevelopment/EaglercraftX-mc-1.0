# Eaglercraft 1.0

CREDITS TO [Colbster937](https://github.com/colbster937) for the 1.2.5 version of eaglercraft, which this project is built on.

:-:
This is a fully functional web port of Minecraft 1.0, playable in any modern web browser. <br> It currently supports only Singleplayer.

> [!WARNING]
> This version of Eaglercraft hasn't got the best performance. I'm aware but can't fix much of that.


## Quick Start
### Play Now:

**Client:** https://beaconlauncher.github.io/


### Offline Downloads:
You can grab the latest build here from the [releases](https://github.com/DutchDucksDevelopment/EaglercraftX-mc-1.0/releases) or compile it yourself.

## Compiling
Run the `CompileClient` script to build the JavaScript and WASM-GC clients. The results will be in the `client` folder.
